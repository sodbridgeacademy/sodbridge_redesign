Professional Programme

Cybersecurity Professional Programme

Develop practical cybersecurity skills through security operations, defensive security, ethical hacking, cloud security and incident response. Build the knowledge, practical experience and portfolio needed to pursue entry-level cybersecurity roles and internships.

10 Weeks 3 Sessions / Week 90–120 Minutes / Session
Weeks 1–2

Security Operations & Professional Practice

Understand how security teams monitor, investigate and respond to cybersecurity events.

Security Operations

SOC fundamentals, security monitoring, alerts and events.

Logs & SIEM

Understanding logs, events, SIEM concepts and investigation.

Incident Response

Identify, investigate, contain and document security incidents.

Professional Practice

Documentation, reporting, teamwork and responsible use of AI tools.

Weeks 3–5

Defensive Security

Learn how organisations protect systems, networks and users against common threats.

Network Security

Firewalls, network monitoring, secure communication and traffic analysis.

Linux Security

Permissions, services, processes, users and system hardening.

Vulnerability Assessment

Identify, assess, prioritise and document vulnerabilities.

Threat Detection

Indicators of compromise, suspicious activity and basic threat hunting.

Security Hardening

Practical approaches to reducing attack surfaces and improving system security.

Security Reporting

Turn technical findings into clear professional security reports.

Weeks 6–7

Offensive Security

Understand how ethical security testing is performed in controlled environments to identify weaknesses before attackers can exploit them.

Reconnaissance

Information gathering and attack-surface identification.

Scanning & Enumeration

Discover services, systems and potential weaknesses in controlled labs.

Web Security

OWASP Top 10, authentication weaknesses and common web vulnerabilities.

Ethical Hacking Labs

Practical exercises and CTF-style challenges in authorised environments.

Weeks 8–9

Cloud, Identity & Governance

Understand the security responsibilities that extend beyond individual devices and networks.

Identity & Access Management

Authentication, authorization, least privilege and account security.

Cloud Security

Cloud security concepts, shared responsibility and common misconfigurations.

Risk & GRC

Risk assessment, policies, controls and governance fundamentals.

Security Documentation

Policies, risk registers, incident reports and professional documentation.

Week 10

Cybersecurity Capstone

Apply your knowledge to a realistic simulated organisation and present your security recommendations.

Secure a Small Organisation

✓ Identify security weaknesses
✓ Assess security risks
✓ Investigate a simulated incident
✓ Recommend security controls
✓ Harden selected systems
✓ Produce a professional security report
✓ Present findings and recommendations
✓ Defend technical decisions
